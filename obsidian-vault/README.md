# Obsidian vault: Animated Cards

This folder is a self-contained **Obsidian vault** for the animated-card project
research and product thinking.

**To open it:** Obsidian → *Open folder as vault* → select this `obsidian-vault`
folder. Start at [[Home]].

Notes:
- `Home.md` — map of content (start here)
- `Research Brief.md` — the deep-research prompt/scope
- `Market Research.md` — the full research report
- `Initial Recommendations.md` — early product/architecture decisions

The canonical copies also live in `../research/` at the repo root; the vault
copies are the same content, named for readability inside Obsidian.
